# I-17 — Matriz formal de cobertura V1 pré-produção

Esta matriz consolida cobertura já existente. Ela não considera nome de arquivo como prova: cada célula aponta para uma asserção/teste específico e seu comportamento observado. O objetivo do fechamento V1 é manter, para cada domínio obrigatório, ao menos um happy path e um failure path explícitos.

## Notas de escopo

- A matriz referencia somente testes versionados e determinísticos; não requer conta, OAuth, cartão ou cliente real.
- A cobertura Google acima valida modelo desejado, idempotência/staleness e filas sem iniciar OAuth real.
- A cobertura Kommo valida projeção, outbox e isolamento com a integração desabilitada; não habilita Kommo LIVE.
- Testes de provider usam dados sintéticos/tokenizados. Nenhuma cobrança real é necessária para o gate formal.
- Esta consolidação não substitui o gate CI: os testes continuam obrigatórios no pipeline e a célula só permanece `COBERTO` enquanto as asserções citadas existirem e estiverem verdes.

## Resultado

Os sete domínios exigidos pelo I-17 possuem happy path e ao menos um failure path específico e rastreável. I-17 pode ser considerado fechado após este documento entrar em `main` com CI verde.
